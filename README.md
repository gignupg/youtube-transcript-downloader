# YouTube Transcript Downloader

Chrome extension (Manifest V3) for downloading transcripts from YouTube videos.

## Install locally (developer mode)

1. Open `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this project folder
5. Pin the extension and click its icon — you should see the "Hello world" popup

## Project layout

- `manifest.json` — MV3 manifest, defines the toolbar action and popup
- `popup.html` / `popup.css` / `popup.js` — extension popup UI
- `icons/` — toolbar icons
